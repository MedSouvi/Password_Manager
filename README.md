# Password Manager

## Description

**Password Manager** est une application développée en Python permettant de gérer des mots de passe de manière simple grâce à une interface graphique.

Les données sont enregistrées dans un fichier JSON afin de conserver les informations entre les différentes utilisations du programme.

## Fonctionnalités

* Ajouter un nouveau mot de passe.
* Enregistrer le nom d'utilisateur et l'application associée.
* Supprimer un mot de passe enregistré.
* Validation des informations saisies.
* Sauvegarde automatique des données au format JSON.
* Interface graphique simple et intuitive.

## Technologies utilisées

* Python 3
* Tkinter
* JSON

## Installation

1. Téléchargez ou clonez ce dépôt.
2. Vérifiez que Python 3 est installé.
3. Ouvrez le dossier du projet.

## Exécution

Exécutez le fichier principal du projet avec Python.

## Structure du projet

* `main.py` : point d'entrée de l'application.
* `control.py` : gestion des fonctionnalités.
* `passwords.json` : stockage des mots de passe.
* `icons/` : icônes de l'application.

## Objectif

Ce projet a été développé dans le but d'améliorer les compétences en Python, en programmation orientée objet, en manipulation de fichiers JSON et en création d'interfaces graphiques avec Tkinter.
